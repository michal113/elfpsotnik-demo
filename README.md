# Elf Psotnik — demo sklepu

Wersja demonstracyjna sklepu internetowego **elfpsotnik.pl**: figurki świątecznego elfa, akcesoria, pliki PDF do druku i chatbot-elf Psotek.

Podgląd na żywo: https://michal113.github.io/elfpsotnik-demo/

Całość to jeden plik index.html, bez backendu. Ceny, opinie i dane produktów są przykładowe.
